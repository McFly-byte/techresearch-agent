# 配置、运行模式与外部依赖

## 配置来源

`src/core/config.py` 使用 `pydantic-settings`，优先级为：

```text
环境变量 > .env 文件 > 代码默认值
```

`get_settings()` 带缓存；测试修改环境变量后需要调用 `get_settings.cache_clear()`。

## fake 与 live

### fake 模式

- 默认模式。
- 固定搜索结果、固定文档、FakeLLM。
- 即使环境中存在真实 Key，也必须保持零网络。
- 报告顶部会显示测试数据警告。
- 用于本地开发、单元测试、CI 和演示。

### live 模式

- 要求 `TAVILY_API_KEY`。
- 要求可解析为 Qwen 的真实 LLM 配置和 `DASHSCOPE_API_KEY`。
- 缺配置时明确失败，不回退到 fake。
- 使用真实网页搜索、抓取、事实提取、NLI 和报告综合。

## 主要环境变量

| 变量 | 默认/是否必填 | 用途 |
|---|---|---|
| `DASHSCOPE_API_KEY` | fake 可空，live 必填 | Qwen API 密钥 |
| `LLM_PROVIDER` | `auto` | `auto` / `fake` / `qwen` |
| `QWEN_MODEL` | 配置默认值 | 主模型 |
| `QWEN_MODEL_FAST` | 配置默认值 | 预算告警时的便宜模型 |
| `QWEN_VERIFIER_MODEL` | 配置默认值 | 引用 NLI 模型 |
| `QWEN_BASE_URL` | DashScope 兼容地址 | 模型 API 基址 |
| `TAVILY_API_KEY` | fake 可空，live 必填 | Web 搜索 |
| `LANGCHAIN_TRACING_V2` | `false` | 是否启用 LangSmith 追踪 |
| `LANGCHAIN_API_KEY` | 可空 | LangSmith 密钥 |
| `LANGCHAIN_PROJECT` | `tech-research-agent` | 追踪项目名 |
| `PROMPT_SOURCE` | `local` | `local` / `langsmith` / `hybrid` |
| `RESEARCH_TIMEOUT_SECONDS` | 代码默认 600 | 单任务墙钟超时 |
| `TASK_STORE_PATH` | 空 | 非空时保存任务 JSON |
| `MEMORY_ENABLED` | `false` | 长期记忆开关 |
| `MEMORY_NAMESPACE` | `session/default` | 记忆命名空间 |
| `MAX_TOTAL_TOKENS` | 500000 | 全局 token 上限 |
| `PER_TASK_TOKEN_BUDGET` | 空 | 可选单任务 token 上限 |
| `MAX_SEARCH_ROUNDS` | 10 | 每任务搜索轮次上限 |
| `MAX_WORKERS` | 3 | 并发 Worker 上限 |
| `WARNING_TOKEN_RATIO` | 0.8 | 警告阈值 |
| `CRITICAL_TOKEN_RATIO` | 0.95 | 紧急阈值 |
| `TASK_STORE_PATH` | 空 | 任务记录持久化文件 |
| `FEISHU_APP_ID` 等 | 可空 | 飞书报告导出 |
| `CORS_ORIGINS` | 本地前端地址 | 逗号分隔的允许来源 |

注意：`.env.example` 可能落后于 `Settings`。新增或修改配置时，必须同时更新两处并补测试。

## 安全读取配置

- 不要打印 `Settings.model_dump()` 的原始结果。
- 用户可见或日志输出统一使用 `safe_dict()`。
- 密钥字段使用 `SecretStr`。
- `.env` 已被 Git 忽略，不应提交。

## Prompt Hub

本地 Prompt 清单位于 `src/core/prompts/manifest.json`，同步状态位于 `manifest.lock.json`。

常用命令：

```powershell
tra prompts list
tra prompts validate
tra prompts sync --dry-run
tra prompts sync
tra prompts pull 名称或标识
tra prompts promote 名称 --tag production
```

- `local`：只读本地清单，零网络。
- `langsmith`：强制远端，失败即报错。
- `hybrid`：优先远端，失败回退本地。

## 外部集成边界

- Tavily：只在 live 研究链路使用。
- DashScope/Qwen：模型 Provider 使用 OpenAI 兼容接口。
- LangSmith：缺 Key 或 fake 模式时使用 no-op tracing。
- 飞书：导出失败不得破坏本地报告。
- arXiv：当前用于简单 CLI 管线；主 ResearchRunner 以 Web 搜索为主。
