# 术语表

| 术语 | 含义 |
|---|---|
| Agent | 执行规划、搜索、提取或验证等任务的逻辑角色 |
| Planner | 将用户问题拆成 SubTask 的组件 |
| Supervisor | 根据依赖、状态和并发槽位决定派发哪些任务 |
| Worker | 对一个 SubTask 执行搜索、抓取、提取和反思循环 |
| Collector | 收集并发 Worker 结果后重新进入调度 |
| Replan | 证据不足时新增 follow-up 任务 |
| ResearchState / GraphState | LangGraph 顶层共享状态 |
| Reducer | 合并并发状态更新的函数 |
| SubTask | Supervisor 可调度的最小研究任务 |
| Fact | 从来源正文中提取、带引用 ID 的事实 |
| Citation | 来源记录，包含 ID、URL/路径和元信息 |
| Claim | 报告验证阶段的可判定声明 |
| Evidence | 重新抓取后用于判断 Claim 的证据窗口 |
| NLI | 自然语言推断，判断证据是否蕴含、矛盾或不足 |
| CitationVerifier | 重新抓取来源并执行 NLI 的验证器 |
| VerifiedReportBuilder | 应用来源策略、验证、修订并输出报告的构建器 |
| SourcePolicy | 禁用 URL/域名/标题和 as-of 截止日期规则 |
| fake 模式 | 固定数据、固定模型、零网络的离线模式 |
| live 模式 | 使用 Tavily、Qwen 和真实网页的联网模式 |
| BudgetReservation | LLM 调用前预留 token 的一次性票据 |
| partial | 因预算等原因停止但已有部分事实的终态 |
| Prompt Hub | 本地 Prompt 清单与 LangSmith 远端管理机制 |
| Prompt lock | 记录 Prompt 已同步 commit 与 tag 的锁文件 |
| TaskStore | API 任务、事件和报告的本地记录容器 |
| SSE | 服务端向浏览器单向推送事件的协议 |
| EvalPrompt | 评测 answerer 可见的最小输入，不含答案和 rubric |
| EvalQuestion | Judge 使用的完整评测题目与 rubric |
| FixtureDataset | 仅用于离线测试的合成评测数据 |
| DRB2 | DeepResearch Bench II |
| LLM-as-judge | 使用模型依据 rubric 评判答案 |
| blocked rubric | 不适用/被屏蔽的 rubric，记 -1 且不参与均值 |
| as-of | 报告允许使用信息的截止年份 |
| quality gate | 对最终报告非空、非回显和引用可追溯性的硬检查 |
| provenance | 数据来源和处理路径的可追溯记录 |
