# 项目概览

## 一句话定位

TechResearch Agent 是一个面向技术调研的多智能体研究应用：它将问题拆成子任务，执行搜索、抓取、事实提取和反思循环，生成带引用的报告，并对引用重新抓取和验证。

## 当前交付形态

项目同时提供：

- Python CLI：环境检查、配置查看、简单调研、完整图执行、Prompt 管理。
- FastAPI 服务：创建任务、查询状态、读取报告、SSE 进度、取消任务、飞书导出。
- React 前端：创建任务、查看进度、查看历史、下载 Markdown、触发飞书导出。
- 评测工具：离线 fixture、DeepResearch Bench II 适配、可续跑结果目录、rubric judge 和 LangSmith Experiment 接口。

## 核心价值

### 1. 可控的多智能体编排

`src/graph/builder.py` 使用 LangGraph 组织 Planner、Supervisor、Worker、Collector、Replan 和 Writer。Supervisor 路由是项目自行实现的纯函数，便于测试并发、依赖和失败传播。

### 2. 可追溯事实与引用

事实 `Fact` 必须持有来源引用 ID；报告构建前会检查引用 ID 是否存在。Worker 的事实与引用还带 `source_task_id`，可追溯到具体子任务。

### 3. 引用回查验证

`CitationVerifier` 不直接相信首次抓取的片段，而是重新抓取来源、定位相关证据窗口，再做三分类判断：蕴含、矛盾或证据不足。抓取失败与 NLI 失败会单独保留，不伪装成普通的“中立”。

### 4. 有界执行

预算管理覆盖全局 token、单任务 token、搜索轮次、Worker 迭代次数和重规划次数。LLM 调用前采用“预留—提交/释放”的票据模型，减少并发下超预算和泄漏风险。

### 5. 离线优先

默认 `fake` 模式使用固定搜索结果、固定网页内容和 FakeLLM，不联网、不依赖密钥，适合开发与测试。`live` 模式缺少真实搜索或模型密钥时会直接失败，不会悄悄降级。

## 技术栈

| 范围 | 主要技术 |
|---|---|
| 后端 | Python 3.11+、FastAPI、Pydantic、httpx |
| 编排 | LangGraph |
| 搜索与抓取 | Tavily、Trafilatura、arXiv、pypdf |
| 模型 | FakeLLM、Qwen OpenAI 兼容接口 |
| 可观测性 | LangSmith，可关闭 |
| 前端 | React 18、TypeScript、Vite |
| 测试 | pytest、Vitest、Playwright |
| 质量 | Ruff、mypy |

## 仓库主要目录

```text
src/                 后端与 Agent 核心代码
  agents/            规划、调度、Worker、反思、预算和错误分类
  api/               FastAPI、任务存储、后台执行器
  core/              配置、Provider、Prompt Hub、日志与追踪
  domain/            领域模型与验证模型
  graph/             LangGraph 状态、Reducer 和图构建
  service/           提取、报告、验证、检索、记忆和导出
  tools/             搜索、抓取与协议
web/                 React 前端与浏览器测试
evals/               评测适配、runner、judge、图表与运行输出
tests/               后端单元和端到端测试
docs/                历史设计、实施记录和手册
knowledge-base/      当前实现知识库
research/            调研资料与审计材料
```

## 当前成熟度

当前项目是可运行、可测试的研究型 MVP，不是生产级 SaaS。它具备完整的本地演示链路和真实服务适配器，但认证、多用户、分布式任务队列、生产部署、高可用存储等能力仍未建设。
